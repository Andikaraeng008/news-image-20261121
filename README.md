A front page for Saturday 21 November 2026: twelve stories from the day's world news — Russia's strikes on Ukraine reaching Poland, the AI stock sell-off, the ICJ's Rohingya genocide ruling and more — drawn as one 1024×1024 image by a deterministic Python program.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Python 3.13, Pillow only. The program writes `out/entry.png`. The `fonts/` directory bundles the open DejaVu and Liberation Serif fonts it draws with, so it runs anywhere without system fonts installed.
